# Support KB — Access Request Process

## How to request access to a system

1. Identify the system name (e.g., Reporting System, Analytics Dashboard)
2. Determine the required role (Viewer, Editor, Admin)
3. Obtain manager approval (email or ticket reference)
4. Submit request via Support Intake or IT Service Desk

## Standard roles — Reporting System

| Role | Permissions |
|------|-------------|
| REPORT_VIEWER | Read reports, export CSV |
| REPORT_EDITOR | Create and edit reports |
| REPORT_ADMIN | Manage users and schedules |

## Processing time

- Standard requests: 1–2 business days
- Urgent Production access: same business day with manager approval

## Permissions issue (existing user)

If you previously had access and it stopped working:
1. Check if your role was revoked (audit emails sent monthly)
2. Verify you are on the correct environment (Production vs Staging)
3. Re-submit access request if role was removed due to inactivity (90 days)
